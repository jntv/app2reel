# Local API contracts

Last reviewed: 2026-10-27. Source: `server/index.ts`, `store.ts`, `shared/types.ts`, `src/main.tsx`. All endpoints below are implemented. Consumer: local React studio. Auth: the local OS user, exact loopback Host/Origin checks; mutations require application/json. No remote multi-user access is supported. Malformed requests return400, rejected origins403, unsupported media415, busy jobs409, absent projects404.

| GET `/sample-product` | Verification | Interactive fictional Orbit HTML | Sample browser exploration and capture. |

Exact structures are in `shared/types.ts`. Older projects without renderSettings use product styling, cinematic movement, local Natural narration, burned subtitles and pointer effects. Natural voices require one-time setup; System is an explicit choice. New capture writes Project.cursorTrack (time, normalized coordinates, event kind), never input text; the API does not accept arbitrary telemetry edits. Errors are JSON `{error: string}`. Job stages: draft, researching, exploring, review, rendering, complete, failed, cancelled. Side effects are local files/browser activity and subscription-backed inference when sample=false. Server shutdown clears saved logins. Project.productTheme records palette/font/radius/provenance. Shot.entryStart/entrySettled/actionStart/actionEnd preserve real interaction timing. Future OAuth adapters have no API contract yet.
